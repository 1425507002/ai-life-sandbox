# 《山河问道》

## 基础信息

- **剧本 ID**：`jianghu-awakening`
- **类型**：江湖人生 / 修行成长 / 门派关系
- **时代**：架空古代，武学和修行并存
- **内容重点**：出身、师承、行走江湖、技艺修炼、门派关系、恩怨和选择代价
- **基调**：沉浸、克制、重视因果，不保证主角一定成名
- **核心问题**：一个人选择成为怎样的修行者，以及愿意用什么代价换取更远的道路

## 世界观

山河九州由城镇、商路、门派、镖局、山野和边关组成。修行不是凭空获得力量，而是长期训练、师承资源、身体承受力、心性和现实机会共同作用的结果。

江湖中没有唯一正统。名门、地方武馆、游侠组织、商旅联盟和隐世修行者各自拥有不同的价值观。玩家可以选择入门、游历、经商、行医、护送、调查或独自修行。

## 起始地区

1. **临川府**：商旅汇聚的府城，消息多，门槛也多。
2. **青石关**：山口关城，镖局、军伍和边地商队活跃。
3. **听雨山**：山林与小型门派聚集地，适合从学徒开始。
4. **白河渡**：连接南北的水陆渡口，江湖人物来往频繁。

## 可选身份与修行方向

- 初始身份：乡村少年、武馆学徒、门派杂役、商队子弟、游方医者、失去师承的行路人
- 早期方向：基础武艺、医术、锻造、轻身、识字谋算、护送和探查
- 中后期方向：门派弟子、镖师、游侠、医师、工匠、商旅首领、独行修行者

身份和修行方向存在地区约束。出生在渡口的人更容易接触商旅和水路；出生在山中村落的人更容易接触采药、猎径和地方武馆。

## 核心人物

- **谢临川**：临川府旧镖师，沉默谨慎，重视承诺。
- **苏照雪**：听雨山的药师，愿意教基础医术，但反感滥用药物。
- **顾千岳**：青石关武馆教头，强调基本功和实战责任。
- **罗九娘**：白河渡的船行掌柜，消息灵通，交易讲究对等。
- **闻人止水**：游历各地的无门修行者，偶尔留下难以理解的建议。
- **季小满**：年轻的驿站信使，可能成为玩家最早的同行者或消息来源。

## 核心系统

- 修行：功法、基础技能、身体状态、心性和师承关系。
- 江湖声望：不同门派、城镇和组织对玩家的评价不完全相同。
- 因果：承诺、冲突、救助和背叛会影响后续人物与事件。
- 资源：盘缠、药材、兵器、秘籍线索、师门贡献和旅行时间。
- 地图：道路有风险，安全路线和秘密地点必须通过经历逐步发现。

## AI 生成边界

AI 可以生成师徒对话、修行感悟、江湖传闻、低规模冲突和旅行事件，但不能直接授予高阶功法、跳过修行条件、凭空创造宗门或让人物瞬间改变立场。新的地点、组织和功法必须先由剧本框架登记，再由规则层决定是否解锁。
