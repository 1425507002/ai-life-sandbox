## 共同设计约束

- 题材、世界观、时代背景、核心规则和内容分级由项目预设。
- 玩家从剧本库选择世界，再选择出生地、年龄阶段和该剧本允许的身份。
- API AI 只能在选定剧本的框架内补充 NPC 对话、生活事件、行动文案和局部地点内容。
- AI 不能改变题材、核心规则、地图边界、年龄限制或直接写入 `GameState`。
- 四个概念稿都采用“世界骨架 → 地图与关系 → 行动与事件 → 开场内容”的分阶段生成方式。
- 具体数值、完整事件链、全部 NPC 和最终 UI 扩展字段留到剧本协议阶段定义。
- 本轮细化会统一记录目标玩家、首轮循环、最小状态、AI 生成槽位、上下文边界、重玩钩子和原型验证问题，便于横向评分。

## 后续转化顺序

1. 评审四个剧本的题材边界和用户定位。
2. 将每个概念稿整理成统一的 `ScriptPackage` 字段表。
3. 先制作最小可运行测试包，验证多剧本切换、存档隔离和 UI 动态字段。
4. 再接入 API AI 的分阶段内容生成，不让 AI 一次生成完整世界。
